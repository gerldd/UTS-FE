# WattWise – Kalkulator Tagihan & Tips Hemat Listrik

WattWise merupakan aplikasi berbasis Flutter yang dikembangkan untuk membantu pengguna memperkirakan biaya tagihan listrik berdasarkan penggunaan perangkat elektronik sehari-hari. Aplikasi ini juga menyediakan informasi dan tips penghematan energi agar pengguna dapat lebih bijak dalam menggunakan listrik.

Proyek ini dikembangkan sebagai bagian dari tugas Ujian Tengah Semester (UTS) mata kuliah Mobile Front-End.

## Fitur Aplikasi

- **Dashboard:** Menampilkan ringkasan estimasi tagihan dan penggunaan listrik.
- **Kalkulator Listrik:** Menghitung perkiraan konsumsi energi dan biaya listrik berdasarkan perangkat elektronik yang digunakan.
- **Manajemen Perangkat:** Menambahkan dan menghapus perangkat elektronik serta mengatur durasi pemakaiannya.
- **Tips Hemat Listrik:** Menyediakan berbagai informasi dan tips untuk mengurangi konsumsi energi.
- **Pencarian dan Kategori:** Memudahkan pengguna menemukan tips penghematan listrik.
- **Autentikasi:** Menyediakan halaman login dan registrasi.
- **Pengaturan Tampilan:** Mendukung Light Mode dan Dark Mode.
- **Responsive Layout:** Menyesuaikan tampilan aplikasi pada berbagai ukuran layar.

## Teknologi yang Digunakan

- **Flutter** – Framework untuk pengembangan aplikasi.
- **Dart** – Bahasa pemrograman utama.
- **Material Design** – Sistem desain antarmuka aplikasi.

## Cara Menjalankan Aplikasi

1. Clone repository:

```bash
git clone https://github.com/gerldd/UTS-FE.git
```

2. Masuk ke direktori proyek:

```bash
cd UTS-FE
```

3. Install dependencies:

```bash
flutter pub get
```

4. Jalankan aplikasi:

```bash
flutter run
```

## Tujuan Pengembangan

WattWise dikembangkan untuk meningkatkan kesadaran pengguna terhadap penggunaan energi listrik melalui perhitungan estimasi biaya dan penyediaan informasi penghematan energi. Aplikasi ini diharapkan dapat membantu pengguna mengelola konsumsi listrik secara lebih efisien.
